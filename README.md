# soshmedia

Website for Sosh Media — static HTML/CSS/JS, no build step.

- `index.html` — intro page, `home.html` — main site
- `css/`, `js/`, `assets/` — styles, scripts, fonts, images, video
- `google-apps-script/Code.gs` — contact form backend (Google Sheet + email alerts)

Run locally:

```bash
python3 tools/serve.py 5173 .
```
